# Форма — личная библиотека упражнений

Статическое приложение на React, TypeScript и Vite. Русский интерфейс, поиск по русскому и английскому названию и алиасам, фильтры, отдельные URL упражнений и подборок. Нет сервера, регистрации, AI-интеграций, загрузки видео и платных сервисов. Данные и изображения хранятся в репозитории.

## Запуск на macOS и в облаке

Нужен Node.js 22.12+ (проверено на Node.js 24.19.0).

```sh
npm ci
npm run dev
```

Открой адрес из вывода Vite в локальном браузере. Команды выполняются из корня `exercise-guide`.

```sh
npm test                  # поиск, фильтры, целостность данных
npm run validate:content  # те же проверки контента отдельно
npm run validate:assets   # наличие файлов изображений
npm run build             # проверка TypeScript и production-сборка в dist/
npm run preview           # просмотр production-сборки
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

На Linux автоматически используется `/usr/bin/chromium`, если он доступен; на macOS — браузер Playwright. Можно задать `CHROMIUM_PATH`. Тесты проходят на размерах Desktop Chrome и iPhone 13 (эмуляция в Chromium, не физический iPhone и не Safari). Они проверяют поиск, фильтры, навигацию, прямые адреса, повторы в подборке, отсутствие горизонтального переполнения и диалог увеличения с Escape и возвратом фокуса. Для проверки увеличения тест подставляет техническое изображение **только в сетевой ответ браузера теста**; оно не является иллюстрацией упражнения.

## Первый оригинал карточки — требуется файл

В чате предоставлен утверждённый визуальный образец DB Squat. Исходный PNG не был доступен как файловое вложение при реализации. Он **не перерисован и не заменён**. Положи оригинал по адресу:

```
public/images/russian_dumbbell_squat_technique_guide.png
```

Карточка уже подключена к этому пути в `src/data/exercises.json`. После добавления файла обнови страницу: превью, полноразмерная карточка и масштабирование заработают автоматически. Изображение показывается целиком, без обрезки и искажения пропорций. До добавления виден честный заполнитель, увеличение отключено, а `npm run validate:assets` сообщает об отсутствующем оригинале. Доступность оригинала и его читаемость при реальном увеличении пока не проверены.

## Реальные данные и демонстрационный пример

- `src/data/exercises.json`: одно подтверждённое по предоставленной карточке упражнение — DB Squat.
- `src/data/workouts.json`: пустой список реальных тренировок. Состав видео не подтверждён.
- `src/data/workouts.fixtures.json`: **отдельный** пример структуры HASfit, не фактическая последовательность видео. Повторный DB Squat добавлен только для демонстрации разных вхождений одной записи. Пример скрыт до нажатия «Показать пример», помечен на странице и использует отдельный URL `/examples/workouts/...`.

Видео не анализировалось: ранее доступ к YouTube блокировался сетевым прокси. Не выдавайте демонстрационный пример за тренировку. Не добавляйте упражнения по догадке.

## Архитектура

- `src/data/` — локальные JSON-данные и TypeScript-типы.
- `src/lib/content.ts` — поиск и проверка структуры, категорий, идентификаторов, порядка и ссылок.
- `src/components/` — общая оболочка и изображения с увеличением.
- `src/pages/` — каталог, упражнение, список подборок, подборка и 404.
- `src/App.tsx` — маршрутизация и обработка ошибок данных.
- `src/styles.css` — общие стили, компоненты, адаптивность; системные шрифты, без внешних CDN.
- `docs/CONTENT.md` — инструкция добавления контента через Codex.

Фильтры хранятся в query-параметрах и переживают перезагрузку. Нет избранного, отслеживания тренировок и пользовательских заметок.

## Статическое размещение

Загрузи содержимое `dist/` на статический хостинг с HTTPS. Приложение рассчитано на корень домена. Все неизвестные **страничные** URL должны возвращать `index.html` с HTTP 200 (SPA fallback), иначе прямые адреса `/exercises/db-squat` не будут работать. Статические ассеты должны отдаваться как файлы с корректными MIME-типами.

Для Netlify и Cloudflare Pages включён `public/_redirects`; для другого хостинга настрой аналогичный fallback. Например, в nginx: `try_files $uri $uri/ /index.html;`. Публикация на GitHub Pages потребует отдельной настройки fallback и base path — текущая конфигурация это не предполагает. Развёртывание не выполнялось.
