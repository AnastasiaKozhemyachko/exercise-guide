# Форма — личная библиотека упражнений

Статическое приложение на React, TypeScript и Vite. Русский интерфейс, поиск по русскому и английскому названию и алиасам, фильтры, отдельные URL упражнений и подборок. Нет сервера, регистрации, AI-интеграций, загрузки видео и платных сервисов. Данные и изображения хранятся в репозитории.

## Запуск на macOS и в облаке

Нужен Node.js 22.12+ (проверено на Node.js 24.19.0).

```sh
npm ci
npm run dev
```

Открой адрес из вывода Vite в локальном браузере. Команды выполняются из корня `exercise-guide`.

```sh
npm test                  # поиск, фильтры, целостность данных
npm run validate:content  # те же проверки контента отдельно
npm run validate:assets   # наличие файлов изображений
npm run build             # проверка TypeScript и production-сборка в dist/
npm run preview           # просмотр production-сборки
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

На Linux автоматически используется `/usr/bin/chromium`, если он доступен; на macOS — браузер Playwright. Можно задать `CHROMIUM_PATH`. Тесты проходят на размерах Desktop Chrome и iPhone 13 (эмуляция в Chromium, не физический iPhone и не Safari). Они проверяют поиск, фильтры, навигацию, прямые адреса, повторы в подборке, отсутствие горизонтального переполнения и диалог увеличения с Escape и возвратом фокуса. Увеличение проверяется на настоящем PNG приседа. Отдельная проверка принудительно блокирует файл, чтобы проверить заполнитель и отключение увеличения.

## Контент HASfit

Импортирован предоставленный архив `HASfit_Exercise_Library_Codex_Complete.zip`:

- 13 упражнений и 13 полноразмерных PNG в `public/images/hasfit/`;
- одна подборка HASfit с 25 вхождениями, включая все повторы;
- исходные метаданные и контрольные суммы в `docs/hasfit-source/`;
- утверждённый **дизайн-эталон** в `docs/design/EXERCISE_CARD_V1_REFERENCE.png`, отдельно от пользовательских карточек.

Все упражнения имеют статус `needs-review`: это предоставленные AI-иллюстрации, а не кадры видео или профессионально проверенные инструкции. На каждой странице сначала видны замечания; полноразмерная карточка открывается через «Посмотреть черновик карточки». Изображения сохранены без изменения байтов, без обрезки и искажения пропорций, доступны увеличение и прокрутка. Превью каталога тоже помечены как черновики.

Порядок 25 вхождений **не проверен по MP4** (`verificationStatus: sequence-unverified`): видео в архиве отсутствует. Предыдущий MP4 не удалось передать в среду из-за лимита 32 МиБ. Подборка не объявляется готовой программой.

При визуальной проверке найдены перепутанные изображения мостика и Pendulum March: ссылки исправлены по заголовкам и позам, исходные имена PNG сохранены. В V-Sit Reach согнутые колени ошибочно названы ошибкой, хотя они могут быть допустимым облегчением. Текст внутри картинки не редактировался; замечание видно до раскрытия черновика. Полный отчёт — [HASfit_IMPORT.md](docs/HASfit_IMPORT.md).

Существующий DB Squat вручную сопоставлен с тем же упражнением пакета. Сохранились URL `/exercises/db-squat`, поисковые алиасы и категории. Канонический ID теперь `db-squat`; прежний `ex-db-squat` сохранён в `legacyIds` и продолжает разрешаться валидатором и интерфейсом. Автоматического слияния по похожему названию нет.

Отдельный старый демонстрационный пример остаётся в `workouts.fixtures.json`, скрыт до нажатия «Показать пример» и не смешивается с импортированной предварительной подборкой.

## Архитектура

- `src/data/` — локальные JSON-данные и TypeScript-типы.
- `src/lib/content.ts` — поиск и проверка структуры, категорий, идентификаторов, порядка и ссылок.
- `src/components/` — общая оболочка и изображения с увеличением.
- `src/pages/` — каталог, упражнение, список подборок, подборка и 404.
- `src/App.tsx` — маршрутизация и обработка ошибок данных.
- `src/styles.css` — общие стили, компоненты, адаптивность; системные шрифты, без внешних CDN.
- `docs/CONTENT.md` — инструкция добавления контента через Codex.

Фильтры хранятся в query-параметрах и переживают перезагрузку. Нет избранного, отслеживания тренировок и пользовательских заметок.

## Бесплатная публикация на GitHub Pages

Репозиторий публичный. Публичный адрес проекта:

https://AnastasiaKozhemyachko.github.io/exercise-guide/

Для повторной публикации из корня проекта:

```sh
npm ci
npm test
npm run deploy:pages
```

Скрипт проверяет наличие изображений, собирает `build:pages` с префиксом `/exercise-guide/` и отправляет только готовые файлы в ветку `gh-pages`. Нужен доступ к push в этот репозиторий и настроенные `git user.name` / `git user.email`. Скрипт работает в новой временной папке и сохраняет историю существующей ветки публикации; исходный checkout не сбрасывает. Для изменения самого приложения отдельно коммитьте и отправляйте исходники в `main`. Обычный push в `main` **не обновляет сайт автоматически** — повторно выполните `npm run deploy:pages`.

В GitHub → Settings → Pages выберите **Deploy from a branch**, ветку **gh-pages**, папку **/(root)**. GitHub выполняет публикацию асинхронно; статус доступен в Pages / Actions. Пользовательский домен и платный тариф не требуются для этого публичного репозитория.

В Pages-сборке ссылки используют hash-маршруты, например `/exercise-guide/#/exercises/db-squat`: такие адреса работают при открытии и перезагрузке без серверных правил SPA. Изображения и favicon учитывают префикс проекта. При локальной разработке (`npm run dev`) и обычной сборке (`npm run build`) сохраняются адреса `/exercises/db-squat` с BrowserRouter.

## Другой статический хостинг

Для размещения в корне другого домена выполните `npm run build` и загрузите содержимое `dist/`. В этом режиме все неизвестные **страничные** URL должны возвращать `index.html` с HTTP 200 (SPA fallback). Для Netlify и Cloudflare Pages включён `public/_redirects`; пример nginx: `try_files $uri $uri/ /index.html;`. Это правило не используется для GitHub Pages: там работает отдельная сборка с hash-маршрутами.
