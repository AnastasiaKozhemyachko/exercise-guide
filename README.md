# Форма — личная библиотека упражнений

Статическое приложение на React, TypeScript и Vite. Русский интерфейс, поиск по русскому и английскому названию и алиасам, фильтры, отдельные URL упражнений и подборок. Нет сервера, регистрации, AI-интеграций, загрузки видео и платных сервисов. Данные и изображения хранятся в репозитории.

## Запуск на macOS и в облаке

Нужен Node.js 22.12+ (проверено на Node.js 24.19.0).

```sh
npm ci
npm run dev
```

Открой адрес из вывода Vite в локальном браузере. Команды выполняются из корня `exercise-guide`.

```sh
npm test                  # поиск, фильтры, целостность данных
npm run validate:content  # те же проверки контента отдельно
npm run validate:assets   # наличие файлов изображений
npm run build             # проверка TypeScript и production-сборка в dist/
npm run preview           # просмотр production-сборки
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

На Linux автоматически используется `/usr/bin/chromium`, если он доступен; на macOS — браузер Playwright. Можно задать `CHROMIUM_PATH`. Тесты проходят на размерах Desktop Chrome и iPhone 13 (эмуляция в Chromium, не физический iPhone и не Safari). Они проверяют поиск, фильтры, навигацию, прямые адреса, повторы в подборке, отсутствие горизонтального переполнения и диалог увеличения с Escape и возвратом фокуса. Проверяются также оценки, сохранение после перезагрузки, комментарии, копирование, ZIP с настоящими PNG, импорт JSON и свайпы.

## Контент HASfit

Импортирован предоставленный архив `HASfit_Exercise_Library_Codex_Complete.zip`:

- 13 упражнений и 13 полноразмерных PNG в `public/images/hasfit/`;
- одна подборка HASfit с 25 вхождениями, включая все повторы;
- исходные метаданные и контрольные суммы в `docs/hasfit-source/`;
- утверждённый **дизайн-эталон** в `docs/design/EXERCISE_CARD_V1_REFERENCE.png`, отдельно от пользовательских карточек.

Исходные статусы `needs-review` сохранены в метаданных: это предоставленные AI-иллюстрации. Карточки в библиотеке и тренировках показываются сразу, без технических баннеров и дополнительного раскрытия. Замечания источника и работа с оценками перенесены в отдельный раздел **Проверка техники**. При импорте изображения сохранялись без изменения байтов. Затем по явному запросу пользователя заменена только карточка DB Short Step Lunge; остальные 12 PNG не изменены. Доступны увеличение, прокрутка и перетаскивание.

Порядок 25 вхождений **не проверен по MP4** (`verificationStatus: sequence-unverified`): видео в архиве отсутствует. Предыдущий MP4 не удалось передать в среду из-за лимита 32 МиБ. Подборка не объявляется готовой программой.

При визуальной проверке найдены перепутанные изображения мостика и Pendulum March: ссылки исправлены по заголовкам и позам, исходные имена PNG сохранены. В V-Sit Reach согнутые колени ошибочно названы ошибкой, хотя они могут быть допустимым облегчением. Текст внутри других PNG не редактировался. Все 13 карточек затем одобрены пользователем; это не является профессиональной сертификацией. Полный отчёт — [HASfit_IMPORT.md](docs/HASfit_IMPORT.md).

Существующий DB Squat вручную сопоставлен с тем же упражнением пакета. Сохранились URL `/exercises/db-squat`, поисковые алиасы и категории. Канонический ID теперь `db-squat`; прежний `ex-db-squat` сохранён в `legacyIds` и продолжает разрешаться валидатором и интерфейсом. Автоматического слияния по похожему названию нет.

Старый демонстрационный пример сохранён в `workouts.fixtures.json` и по прежнему URL `/examples/workouts/hasfit-legs-example`. Из каталога тренировок промоблок примера удалён.

## Проверка техники и отправка в ChatGPT

1. Открой **Проверка** в навигации (`/#/review` на GitHub Pages).
2. Нажми на изображение: полный просмотр с масштабом, перетаскиванием увеличенной картинки, стрелками, клавишами ←/→ и Escape. На телефоне листай свайпом при масштабе 100%; при увеличении перетаскивай изображение.
3. Для каждой карточки выбери **Всё хорошо**, **Нужны исправления** или **Пока не проверено**. При необходимости исправлений заполни многострочный комментарий. Решение можно изменить; карточка остаётся доступной.
4. **Скопировать результаты проверки** копирует один отчёт по всем карточкам, независимо от текущего фильтра. При отказе clipboard появится поле для ручного копирования.
5. **Скачать ZIP для ChatGPT** скачивает `technique-review.zip`: `review-report.md`, `review-results.json` и `cards/<exercise-id>.png` с оригинальными байтами всех 13 карточек. Имена и пути явно указаны в JSON. Оценки и комментарии не очищаются.

Оценки сохраняются в `localStorage` с ключом `exercise-guide.technique-review.v1`, отдельно от `src/data`. Они переживают перезагрузку и обычное закрытие браузера, но привязаны к браузеру и origin. Очистка данных сайта/приватного окна может удалить их. Для переноса на другое устройство распакуй ZIP и выбери **Импортировать JSON** → `review-results.json`. Совпадающие ID обновляются; остальные текущие оценки сохраняются. Комментарии сохраняются и экспортируются без обрезки и перефразирования, даже если решение затем изменено (Markdown показывает замечания только в группе «Нужны исправления», JSON сохраняет все).

Раздел проверки расположен на публичном статическом сайте и не защищён авторизацией. Личные оценки и комментарии серверу не отправляются и другим посетителям не видны; исходные изображения и метаданные общедоступны. Пользовательское одобрение не является профессиональной биомеханической сертификацией. В приложение не встроен ChatGPT или другой AI.

## Подтверждённые карточки и миграция старых оценок

Все 13 HASfit-карточек одобрены пользователем. Подтверждения хранятся отдельно от исторических импортированных метаданных в `src/data/review-approvals.json`. По умолчанию раздел проверки показывает только pending / changes_requested; пустая очередь сообщает «Все карточки проверены ✓». Одобренные доступны через фильтры «Всё хорошо» и «Все карточки».

При первом открытии новой версии `migrateConfirmedApprovals` обновляет только 13 явно перечисленных ID. Для выпада старый комментарий очищается. Остальные ID/заметки не сбрасываются. На каждой подтверждённой записи сохраняется `approvalRevision`; последующие ручные изменения с этой ревизией остаются в силе при перезагрузке. Старый JSON без этой ревизии не возвращает прежние коррекции; новый JSON переносит новые решения как раньше. Это не глобальная очистка localStorage.

Утверждённая замена выпада получена из `DB_Short_Step_Lunge_Approved_Codex.zip`, сохранена без изменения размера/байтов, а прежний рабочий файл удалён. Новый URL содержит SHA-256-префикс для обхода старого кэша во всех местах: thumbnail, инструкция, просмотр и ZIP. Манифест происхождения и полного хеша — `docs/approved-card-updates.json`. Исходные 25 ссылок и стабильный ID не менялись.

## Навигация и поиск

Тренировки показывают точное английское имя как основное, русское — как дополнительное. Поиск учитывает оба языка, источник и алиасы. Алфавитная сортировка удалена: сохраняется порядок записей источника. В библиотеке фильтры по мышцам, типу и оборудованию; в тренировках — по направлению, типу и оборудованию. Опции берутся из явных данных, отсутствующие категории оборудования не предлагаются. Названия упражнений в карточках, списках, просмотре и проверке — прежде всего английские; русский вариант остаётся вторичным и участвует в поиске.

Открой тренировку → упражнение: карточка показывается сразу. Стрелки и клавиши ←/→ идут по всем вхождениям, включая повторы; на телефоне работает горизонтальный свайп. Индикатор показывает место в тренировке. Контекст хранится в URL (`workout` и `occurrence`) и переживает перезагрузку; кнопка возврата ведёт в тренировку. Хлебные крошки — обычные рабочие ссылки. При просмотре увеличенной картинки клавиши управляют просмотром, не меняя случайно тренировку под ним.

Обложка HASfit — собственная SVG-композиция библиотеки, а не официальный рекламный материал тренера. Полное исходное название хранится в `nameEn`; архивное `originalTitle` и исходная последовательность сохранены.

## Архитектура

- `src/data/` — локальные JSON-данные и TypeScript-типы.
- `src/lib/content.ts` — поиск и проверка структуры, категорий, идентификаторов, порядка и ссылок.
- `src/components/` — общая оболочка и изображения с увеличением.
- `src/pages/` — каталог, упражнение, список подборок, подборка и 404.
- `src/App.tsx` — маршрутизация и обработка ошибок данных.
- `src/styles.css` — общие стили, компоненты, адаптивность; системные шрифты, без внешних CDN.
- `docs/CONTENT.md` — инструкция добавления контента через Codex.

Фильтры хранятся в query-параметрах и переживают перезагрузку. Нет избранного и отслеживания тренировок. Комментарии к проверке хранятся отдельно от метаданных.

## Бесплатная публикация на GitHub Pages

Репозиторий публичный. Публичный адрес проекта:

https://AnastasiaKozhemyachko.github.io/exercise-guide/

Для повторной публикации из корня проекта:

```sh
npm ci
npm test
npm run deploy:pages
```

Скрипт проверяет наличие изображений, собирает `build:pages` с префиксом `/exercise-guide/` и отправляет только готовые файлы в ветку `gh-pages`. Нужен доступ к push в этот репозиторий и настроенные `git user.name` / `git user.email`. Скрипт работает в новой временной папке и сохраняет историю существующей ветки публикации; исходный checkout не сбрасывает. Для изменения самого приложения отдельно коммитьте и отправляйте исходники в `main`. Обычный push в `main` **не обновляет сайт автоматически** — повторно выполните `npm run deploy:pages`.

В GitHub → Settings → Pages выберите **Deploy from a branch**, ветку **gh-pages**, папку **/(root)**. GitHub выполняет публикацию асинхронно; статус доступен в Pages / Actions. Пользовательский домен и платный тариф не требуются для этого публичного репозитория.

В Pages-сборке ссылки используют hash-маршруты, например `/exercise-guide/#/exercises/db-squat`: такие адреса работают при открытии и перезагрузке без серверных правил SPA. Изображения и favicon учитывают префикс проекта. При локальной разработке (`npm run dev`) и обычной сборке (`npm run build`) сохраняются адреса `/exercises/db-squat` с BrowserRouter.

## Другой статический хостинг

Для размещения в корне другого домена выполните `npm run build` и загрузите содержимое `dist/`. В этом режиме все неизвестные **страничные** URL должны возвращать `index.html` с HTTP 200 (SPA fallback). Для Netlify и Cloudflare Pages включён `public/_redirects`; пример nginx: `try_files $uri $uri/ /index.html;`. Это правило не используется для GitHub Pages: там работает отдельная сборка с hash-маршрутами.
