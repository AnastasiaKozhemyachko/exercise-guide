# Импорт пакета HASfit

Источник: предоставленный пользователем `HASfit_Exercise_Library_Codex_Complete.zip`.

Импортировано 13 записей упражнений, 13 неизменённых PNG и 1 предварительная подборка из 25 вхождений. Карточки не генерировались заново. Эталон дизайна хранится отдельно и не выдается за экспертное подтверждение техники. MP4 в архиве отсутствует; предыдущий загруженный MP4 превышал лимит передачи 32 МиБ. Состав и порядок не сверялись по видео.

## Статусы

**Готовы как проверенные инструкции: 0.** Все 13 записей: `needs-review`.

Изначальные статусы `approved-design-reference` и `needs-technique-and-text-review` сохранены как `sourceStatus`. `imageOrigin` сохранён. Замечания источника находятся в `reviewNote`, дополнительные замечания визуального просмотра — в `reviewIssues`. Исходные JSON сохранены в `hasfit-source/`, чтобы не потерять имена, ID, исходные пути и предварительный порядок.

Карточки показаны как черновики: на странице упражнения перед раскрытием изображения видны происхождение и замечания. Это возможность просмотра предоставленных материалов, а не их утверждение. Исходные изображения с ошибками не исправлялись и не объявляются окончательными инструкциями.

| `one-leg-hip-up` / One Leg Hip Up | **В исходном JSON указан Pendulum March.** Исправлена ссылка на `03_pendulum_march.png`: заголовок и позы в этом файле показывают мостик. Уточнить распределение опоры по стопе. |
| `pendulum-march` / Pendulum March | **В исходном JSON указан мостик.** Исправлена ссылка на `02_one_leg_hip_up.png`: заголовок и позы показывают наклон с подъёмом колена. Точный вариант сверить с видео. |
| `fire-hydrant-pulse` / Fire Hydrant + Pulse | Выноски кистей и коленей указывают на другие части тела. Направление стрелки пульса не задаёт точную траекторию. |

| `db-short-step-lunge` / DB Short Step Lunge | Наклон корпуса и длина шага зависят от варианта. Совет сокращать шаг при ощущениях в колене не универсален. |
| `one-leg-balance` / One Leg Balance | Низкое положение свободного колена само по себе не ошибка. Уточнить требования к высоте подъёма. |

| `page-turner` / Page Turner | Траектория верхней руки не показана ясно. Отрыв плеча от пола не всегда ошибка; не требовать прижимать плечо силой. |
| `side-lying-quad-stretch` / Side Lying Quad Stretch | Движение различимо; не тянуть пятку силой ради обязательной глубины. Подписи дыхания и положения колена требуют проверки. |
| `v-sit-reach` / V-Sit Reach | **Известная ошибка:** согнутые колени названы ошибкой, но могут быть подходящей адаптацией. На рисунке ноги вместе; соответствие названию V-Sit проверить по видео. Замечание выведено до изображения. |

Это предварительный визуальный QA, не медицинская или профессиональная биомеханическая экспертиза. Пометки не подтверждают, что движения присутствуют в видео.

## Сохранение существующего DB Squat

Прежняя библиотека содержала единственный DB Squat с ID `ex-db-squat`, slug `db-squat` и ссылкой на отсутствующее изображение. Импортированная карточка явно представляет то же упражнение и тот же утверждённый дизайн. Поэтому выполнено **ручное** сопоставление:

- канонический ID пакета `db-squat` сохранён;
- прежний ID `ex-db-squat` сохранён в `legacyIds`, и старые ссылки данных продолжают работать;
- публичный URL `/exercises/db-squat` сохранён;
- прежние алиасы и категория «Пресс» сохранены вместе с категориями пакета;
- прежний `verified` исправлен на `needs-review`: источник подтверждает дизайн, а не технику;
- старый демонстрационный пример сохранён отдельно без изменения его исторических ссылок.

Других объединений не выполнялось. Все 13 исходных ID доступны, и повторения тренировки ссылаются на единые записи.

## Контроль целостности

`src/lib/hasfit-import.test.ts` сверяет 25 исходных вхождений, идентификаторы, имена и исходные статусы, доступность прежнего ID, исправление двух ссылок и SHA-256 каждого PNG. Обычные проверки:

```sh
npm run validate:content
npm run validate:assets
npm test
npm run test:e2e
npm run build
```

Браузерные тесты используют реальные изображения: все 13 раскрываются на десктопном и мобильном размерах, сохраняют пропорции и позволяют увеличить карточку приседа. Эмуляция Chromium не заменяет проверку на физическом телефоне.
